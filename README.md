# Blendy Runner Game

## Description

Blendy is an engaging runner game developed using Unity, designed to provide an entertaining experience while incorporating wellness tips and educational elements. Players control a character that runs through dynamically generated segments, collecting coins and fruits while avoiding obstacles. The game features intuitive swipe controls, leaderboard tracking, and interactive lessons to promote healthy habits.

## Features

- **Endless Runner Mechanics**: Infinite levels with procedurally generated segments.
- **Collectibles**: Gather coins and various fruits.
- **Controls**: Swipe gestures for jumping, sliding, and lane changes.
- **Wellness Integration**: In-game tips and lessons on health and wellness.
- **Animations**: Smooth character animations and interactive elements.
- **Multiple Modes**: Different game modes including endless, assessment, and exercise modes.

## Installation

1. **Prerequisites**:
   - Unity 6000.3.10f1 or later.
   - Ensure you have the necessary Unity modules installed (e.g., for input system, text mesh pro).

2. **Clone the Repository**:
   ```
   git clone https://github.com/yourusername/runner-game.git
   cd runner-game
   ```

3. **Open in Unity**:
   - Launch Unity Hub.
   - Add the project by selecting the cloned folder.
   - Open the project in Unity Editor.

4. **Build the Project**:
   - In Unity, go to File > Build Settings.
   - Select Android Platform.
   - Click Build and choose a location for the build.

## Usage

- **Main Menu**: Start a new game, view leaderboard, or access settings.
- **Gameplay**: Use swipe controls to navigate:
  - Swipe up to jump.
  - Swipe down to slide.
  - Swipe left/right to change lanes.
- **Collect Items**: Run into coins and fruits to collect them.
- **Avoid Obstacles**: Colliding with obstacles end the run.
